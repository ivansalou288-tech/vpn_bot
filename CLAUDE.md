# Правила проекта

## Деплой после каждого изменения (обязательно)
После КАЖДОГО изменения кода сразу, без отдельного вопроса:
1. Залить изменённые файлы на основной сервер: `root@89.125.19.221`, каталог `/var/www/panel.ezhqpy.ru/vpn_bot` (scp).
2. Проверить компиляцию: `./venv/bin/python -m py_compile <файлы>`.
3. Перезапустить ОБА процесса: `main.py` и `subscription_api.py`. Они запущены без systemd, через `nohup ./venv/bin/python <файл> >> nohup.out 2>&1 &`.
   - Убивать по pid (`ps -eo pid,cmd | awk ...` → `kill`), НЕ через `pkill -f`: он убивает собственную SSH-сессию.
4. Убедиться, что запущено по одному экземпляру каждого и в `nohup.out` нет ошибок.

Перед заливкой делать резервную копию заменяемых файлов в `/root/vpn_bot_backup_<дата>`.

## Доступ
- Вход по SSH паролем root; пароль в репозиторий не записывать. Его даёт пользователь в чате.
  Для неинтерактивного входа: `SSH_ASKPASS` + `SSH_ASKPASS_REQUIRE=force`, `-o PubkeyAuthentication=no`, `</dev/null`.
- Локально нет `secret.py` (токен/логин панели), он есть только на сервере. Живые тесты запускать на сервере.

## Особенности панели 3x-ui
- `clients/add` НЕ отклоняет повторный email: создаёт дубль с новым UUID. Наличие клиента проверять самим (`getSubById`) и тогда менять дату через `clients/update/{email}`.
- Старый маршрут `/inbounds/{id}/updateClient/` отвечает 404, не использовать.
